# SGS Frontend — Vanilla HTML/CSS/JavaScript

A polished static frontend rebuilt from the uploaded Sports Guild Society project.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Pages
- Home
- About
- Team with year filters and expandable member cards
- Hall of Fame / Results
- Tournament Registration + interactive demo form
- Contact + interactive demo form
- Login / Sign Up
- Admin Dashboard mockup

## Important
This is a frontend-only version. The original Next.js/MongoDB API/authentication has not been converted into a backend. Forms display frontend success states and can later be connected to your existing APIs.
